Ponto de entrada
Roteador / RAG

NL-to-SQL
Ollama (LLM local)
Armazenamento / infra

Regra de fonte única: dashboard/roteador.py e eval/rag_gerador.py existem para nunca duplicar lógica de roteamento/geração entre o dashboard e o harness de avaliação — uma duplicação manual em 3 lugares já causou uma regressão fantasma de 67,9%→52% no passado, corrigida consolidando tudo num só módulo importado por ambos os consumidores. Uma API de diagnóstico em 3 camadas e um servidor MCP existiram no projeto e foram removidos em 2026-09-12 — entregas planejadas para reimplementação futura.
